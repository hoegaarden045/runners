# Управление GitLab Runner через Salt

Репозиторий устанавливает Docker на minion, регистрирует раннер в GitLab и
запускает его через Docker Compose.

## Принцип работы

1. Salt выбирает каталог `salt/gitlab_runner/runners/<minion-id>/` и читает `settings.yaml` и `config.toml.j2`.
2. При первом запуске Salt регистрирует раннер в GitLab через POST. В запрос идут поля из `api` и `registration`. При совпадении ключей приоритет у `registration`. GitLab возвращает ID и токен, Salt сохраняет их в `/opt/runner/config/.runner_auth`.
3. При повторном запуске Salt **пропускает регистрацию**, если существует `.runner_auth`. Для существующего раннера Salt записывает поля из `api` в `.api_params` и отправляет PUT по сохранённому ID при создании или изменении файла.
4. Salt формирует `config.toml` с локальным ID и токеном и запускает Compose через systemd.

Поля в `registration` применяются при создании раннера. Если после POST пропало соединение и ответ не сохранился, перед повтором проверь, создался ли раннер в GitLab.

## Как добавить раннер

1. Скопируй каталог существующего раннера. Имя нового каталога должно совпадать с ID minion. Текущие цели Salt и CI используют шаблон `runner-minon*`.
2. В `settings.yaml` укажи адрес GitLab и заполни `registration`.
   - Для `project_type` укажи `project_id`.
   - Для `group_type` укажи `group_id`.
   - Для `instance_type` достаточно `runner_type`.
3. В `api` укажи описание, теги и другие параметры, которые принимают POST и PUT. В `config.toml.j2` настрой имя, параллелизм и Docker executor.
4. Для первого развёртывания настрой приватный Pillar с `gitlab_api_token` и замени заглушку `salt/gitlab_runner/certs/rootca.crt` на доверенный CA. Токену нужны права `create_runner` для регистрации и `manage_runner` для обновления.
5. Открой merge request. CI проверяет YAML и выполняет Salt dry-run. После merge в `main` CI применяет состояния. Для этого настрой GitFS и переменные `SALT_MASTER_URL`, `SALT_API_USER`, `SALT_API_PASSWORD` и `SALT_API_CA`. Последняя должна быть переменной типа File с CA для Salt API.
